# Contributing

- Use Node 20 (`.nvmrc`) and npm workspaces: `npm install`.
- Before opening a PR run `npm run lint`, `npm run typecheck`, `npm test` and `npm run build`.
- Format code with `npm run format`.
- Commits must not include AI/tool attribution trailers (no `Co-Authored-By` lines for bots or assistants).

## Licence headers

- New source files must start with the Apache 2.0 licence header used in the existing files (copyright line and the "Licensed under the Apache License, Version 2.0" block).
