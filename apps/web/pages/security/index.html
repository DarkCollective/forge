Security

Last updated: 10 November 2026

If you have found a security problem in Forge or this website, please tell us privately first, so that a fix can be prepared before the problem is described in public.

How to report

  • Preferred: use GitHub's private vulnerability reporting for the repository: open a private advisory.
  • Or email david@darkcollective.com.

Include what you found, the steps to reproduce it, the page or version you tested, and what an attacker could do with it. Please do not open a public issue for a vulnerability until a fix is available. We read every report. We cannot promise a response time.

Our contact details for automated tools are published at /.well-known/security.txt.

What is in scope

  • The website at forge.darkcollective.com.
  • The Forge application, including the FL runtime sandbox that runs operations and recipes.
  • Decoding of share links, which is treated as untrusted input.
  • The content security policy and the other response headers.

What is out of scope

  • Denial-of-service testing against the live site.
  • Social engineering of maintainers or users.
  • Problems that need a compromised browser, device or account.
  • Reports about third-party software that have no specific effect on Forge.

The security model in brief

  • No ambient authority. FL has no words for the page, the network, storage or evaluation of code. An operation sees only the values it is given.
  • Sandboxed execution. Recipes run in a web worker, separate from the page, with limits on steps, stack depth, value size and wall-clock time.
  • Strict content security policy. Scripts, styles, workers and connections may come only from this site. There are no inline scripts or styles, and the site cannot be framed.
  • Cross-origin isolation. The site is served with the COOP and COEP headers.
  • Local processing. Your data is processed in your browser. No server receives it. See the privacy page.

Research and recognition

Good-faith security research that follows this page is welcome. We do not offer a bounty or any other payment.
